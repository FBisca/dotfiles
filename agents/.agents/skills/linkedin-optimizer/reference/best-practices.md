## 1. How recruiters find people now
- **AI-assisted search**: recruiters paste a job description/intake notes; LinkedIn matches qualifications even when not exact filters.
- **Hiring Assistant** (LinkedIn's recruiting agent, GA in English since late 2025; 2026 Wave 1 adds evaluating external-ATS applicants, AI follow-ups, AI job-ad targeting) sources and screens on profile content.
- Implication: the AI can only judge what is **written**. Use explicit titles, explicit skills, concrete outcomes; repeat target-role keywords naturally across headline, About, Experience and Skills. No hidden text (it is detected and penalized; also rule 2).
- Classic Recruiter filters still matter: current/past title, skills, location, years of experience, "Open to work", languages.

## 2. Limits
| Field | Limit | Note |
|---|---|---|
| Headline | 220 chars | ~60–70 visible in search results → lead with title + top keywords |
| About | 2,600 chars | ~265 chars show before "see more" → hook first |
| Experience description | 2,000 chars per role | |
| Skills | up to 100 | aim 20–40 relevant; tag 3–5 per role |
| Top/pinned skills | 5 | shown on profile card |
| Custom URL | 3–100 chars | letters/numbers, no spaces/symbols |
| Project description | 2,000 chars | |

## 3. Section-by-section
- **Photo/banner**: clear face, plain background; banner with role/stack or neutral. (User-only action.)
- **Headline formula**: `<Target title> | <3–5 core skills> | <domain/differentiator> | <proof: notable employers or outcome>`. Use the exact title recruiters search (e.g. "Senior Backend Engineer", not "Code Ninja").
- **About**: first person, plain words. 1) hook: who you are + what you do best; 2) 2–3 proof points (what you built, for whom, outcome); 3) how you work/what you care about; 4) what you are looking for (optional); 5) keywords line (optional "Stack: …"). No buzzword salad, no "passionate".
- **Experience**: title = recognizable market title. 2–5 bullets: verb + what + outcome (metric only if true and allowed). One-line company context for unknown companies. Tag skills per role. Condense roles >10 years old.
- **Projects**: real, linkable work (side projects, OSS, apps). Dates, stack, link.
- **Skills**: canonical LinkedIn names; prune irrelevant/outdated; pin the 5 that match target roles.
- **Featured**: portfolio, talks, case studies, best posts.
- **Custom URL**: `/in/firstlast` style.
- **Recommendations**: 2–3 recent ones from managers/peers beat many old ones (user asks for them; rule 6).
- **Activity**: occasional genuine posts help visibility — suggest only, never publish (rule 5).

## 4. Open to Work
- "Recruiters only": no green frame; recruiters using Recruiter can filter on it. LinkedIn tries to hide it from your current company's recruiters but doesn't guarantee it.
- "All LinkedIn members": green #OpenToWork frame; more visibility, visible to employer.
- Titles are picked from LinkedIn's list (up to 5); add locations + remote/hybrid/onsite, start date, employment types.

## 5. ATS-friendly CV
- Single column; no tables for layout, text boxes, images, icons or multi-column templates. Contact info in the body, not header/footer.
- Standard headings: Summary, Experience, Projects, Skills, Education, Languages.
- `.docx` safest for Workday/Taleo/iCIMS; PDF fine for Greenhouse/Lever/Ashby.
- Keywords from target job descriptions inside achievement bullets; spell acronyms both ways once ("Large Language Models (LLMs)").
- Self-test: copy all text from the PDF into a plain editor — it must read in order.
- 1–2 pages; mirror LinkedIn titles/dates exactly (recruiters cross-check).
