# Conversation prep (one block per open row)

```
## <A<n>>: <row in one line>
Who: <role, not a name or client>
Ask: <see below>
Passes if: <the row's test criterion, verbatim> (no test: skip)
Kills the idea: <the answer that means no>
Changes the idea: <the answer that reshapes scope>
Test type data or spike: no conversation (lookup, or `/start-planning` Gather); prototype: `/prototype`; survey: draft the questions.
Outreach: not drafted. Draft only after the user's yes.
```

Mom Test only for how users behave (2-4 questions: past behaviour and specifics):
1. Last time <situation> came up, what did you do?
2. Walk me through how that went: who was involved, what did it cost?
3. What did you try before, and why did it stop working?

A policy or rule owner (finance, compliance, decider) is asked for the current rule: "What is the rule today for <case>? Where is it written? Who can change it?"

Never in a question: the solution's name or pitch, "would you", "if we built".
