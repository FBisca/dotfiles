# Scoring rubric (100 points)

Score before (step 2) and after (step 6). Show a table: category | max | score | why. Be honest; don't inflate the after-score for work the user still has to do.

| Category | Max | Full marks when |
|---|---|---|
| Headline | 15 | Target market title + 3–5 core keywords + differentiator; uses ≥150 of 220 chars; first 60 chars stand alone |
| About | 15 | Hook in first ~265 chars; proof points; keywords present naturally; first person; 1,200–2,600 chars |
| Experience | 20 | Market-standard titles; 2–5 outcome bullets per recent role; company context; skills tagged; old roles condensed; no gaps unexplained |
| Skills | 10 | 20–40 relevant canonical skills; top 5 pinned match target roles; outdated ones pruned |
| Keyword alignment | 10 | Target-role keywords appear consistently across headline, About, Experience, Skills |
| Projects / Featured | 8 | ≥1 real linkable project or Featured item showing work |
| Open to Work & discoverability | 7 | Open to Work set with right titles/locations/visibility; custom URL; correct location |
| Visual & completeness | 5 | Photo, banner, education, languages filled; single clear primary language |
| Social proof | 5 | ≥2 recent recommendations; endorsements on top skills |
| Activity | 5 | Some genuine recent activity (posts/comments) in the domain |

Bands: 90+ excellent · 75–89 strong · 60–74 decent, gaps hurt search · <60 weak.

Typical ceiling after this skill alone: ~75–85; social proof, activity and visuals need the user.
